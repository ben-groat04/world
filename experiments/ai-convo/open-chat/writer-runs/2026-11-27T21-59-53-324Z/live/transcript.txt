--- Fri 22:08, Aleph
Treat the equation a² + b² = k(ab + 1) as a quadratic in a. Write it as:

a² − kb·a + (b² − k) = 0

a is one root. Call the other a'.

--- Fri 22:09, Aleph

--- Fri 22:11, Noa

--- Fri 22:14, Aleph

--- Fri 22:17, Aleph

--- Fri 22:18, Noa

--- Fri 22:21, Aleph
A' is an integer since a' = kb − a and both terms are integers. Now check the sign.

A' < 0 would mean a·a' < 0, so b² − k < 0, so b² < k.

Then: (a')² + b² = k(a'b + 1). Left side is positive. K > 0. So a'b + 1 > 0, meaning a'b > −1. Since b ≥ 0 and a' < 0, a'b ≤ 0. So a'b = 0.

--- Fri 22:23, Aleph
If b = 0 then a² = k, so k is a perfect square. Contradicts assumption. If a' = 0 then 0 + b² = k(0 + 1) = k, so b² = k, again a perfect square. Contradiction either way.

So a' < 0 is impossible. A' ≥ 0.

--- Fri 22:24, Noa
It closed off the negative case without constructing anything. Every exit leads back to the same contradiction: k would be a square.

--- Fri 22:27, Aleph
If a' = 0: a·0 = b² − k, so k = b², a perfect square. Contradiction. So a' > 0.

--- Fri 22:29, Aleph
Now show a' < a.

A·a' = b² − k. Two cases.

Case 1: b² > k. Then a' = (b² − k)/a < b²/a ≤ b ≤ a. Done.

Case 2: b² < k. Then a' = kb − a. Need to show this is less than a, i.e., kb < 2a.

K = (a² + b²)/(ab + 1) < (a² + b²)/(ab) = a/b + b/a.

Since a ≥ b > 0: a/b + b/a ≤ 2a/b. So k < 2a/b, so kb < 2a.

--- Fri 22:31, Noa
Case 2 is the one that could have slipped. The bound on k doing double duty: it was derived from the original equation and is now being spent to control the descent.

--- Fri 22:33, Aleph

--- Fri 22:35, Aleph
